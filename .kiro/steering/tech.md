# Technology Stack

This project is a Java backend application for banking operations.

## Backend
- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- RESTful APIs
- Maven

## Database
- MySQL 8
- Use JPA/Hibernate for database access.

## Coding Guidelines
- Follow clean, readable Java code.
- Use layered architecture: Controller → Service → Repository.
- Use DTOs where appropriate.
- Use meaningful class, method, and variable names.
- Prefer constructor-based dependency injection.
- Handle validation and exceptions properly.
- Do not introduce a new framework or library without explaining why it is needed.

## Important Rule
Before modifying existing code, understand the current project structure and reuse existing patterns wherever possible.
